Milarepa Video Uploader

Privacy Policy

Effective date: June 21, 2026

Information used

After you authorize the app, TikTok provides an account identifier, basic profile information, an access token, and a refresh token. The uploader also accesses only the local video file that you explicitly select.

How information is used

  • Basic profile information confirms which TikTok account is authorized.
  • OAuth tokens authenticate draft-upload and status requests.
  • The selected video is transmitted directly to TikTok as a creator-reviewed draft.

Storage and sharing

OAuth tokens are stored locally on the creator's computer with restricted file permissions. This website does not receive or retain TikTok tokens or uploaded videos. Information is shared with TikTok only as needed to provide login and draft-upload functionality.

Retention and deletion

Local tokens remain until the creator deletes the app's local token file or revokes access through TikTok. Uploaded drafts and published videos are retained according to the creator's TikTok settings and TikTok's policies.

Security

The client secret is not embedded in public web pages or committed to source control. Local OAuth tokens are written to a git-ignored file with owner-only permissions.

Your choices

You control which videos are uploaded and whether drafts are published. You may revoke the app's access in TikTok and remove local tokens at any time.

Changes

This policy may be updated when the uploader's functionality or TikTok requirements change. The effective date above identifies the current version.
